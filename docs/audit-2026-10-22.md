# Security and bug audit — 2026-10-22

Scope: the live product at autodeploy.fyi (dashboard, API, edge, server-app
gateway, VM) and its code at `33906e4`. Method: a map of every API route and
its guard, code review of each risk area, and read-only probes of production
(no data changed, nothing flooded).

**Priority:** **P1** fix before opening sign-ups (or now, if cheap) ·
**P2** fix soon · **P3** hardening · **P4** nice to have.

## Checked and sound

- **CORS:** only `app.autodeploy.fyi` may read API responses; other origins get no permission.
- **CSRF:** cookie-authenticated writes need the session's CSRF token and an allowed Origin; pre-sign-in routes check Origin.
- **Session cookies:** `__Host-` prefixed, host-only, HttpOnly, Secure, SameSite=Lax; rotated on sign-in; all sessions end on password reset.
- **Tenant isolation:** every route that takes an ID runs inside `withOrg` (Postgres row-level security); org switching checks membership; API tokens can't exceed their creator's role and are created only from a browser session.
- **GitHub webhooks:** HMAC over the raw body; unsigned and wrongly signed requests get 403. Users are matched by GitHub id, organisations can't be taken over by a slug clash, installations by account id.
- **Rate limits** use Cloudflare's real client IP; a faked `X-Forwarded-For` doesn't reset them. Password guessing is also paused per address.
- **Edge:** `..` traversal refused after decoding, and only files in a deployment's own manifest are served.
- **Secrets:** none in the git history (all of it scanned); `.env.prod`, Terraform state and tokens are git-ignored.
- **Dependencies:** `pnpm audit --prod`: 0 known vulnerabilities.
- **No raw HTML from user content** anywhere (no `dangerouslySetInnerHTML`; error pages use fixed text).
- **VM:** no inbound ports (Oracle firewall), SSH key-only and no root, everything else on loopback or the Docker network; the gateway refuses requests without its token.
- **AI:** repository text and logs are fenced as untrusted; patches can't touch CI, lockfiles or `.env`; every AI patch waits for a person's approval.
